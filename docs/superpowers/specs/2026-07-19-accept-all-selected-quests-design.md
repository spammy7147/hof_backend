# 선택 퀘스트 무조건 수락 설계

## 목표

퀘스트 자동화에서 사용자가 선택하고 활성화한 퀘스트가 `수락 가능` 상태이면 미션 종류나 현재 완료 가능 여부와 관계없이 수락한다.

## 동작

- 보상 수령 가능한 선택 퀘스트는 기존처럼 가장 먼저 처리한다.
- 그다음 `수락 가능` 상태인 선택 퀘스트를 원본 페이지 순서대로 수락한다.
- 수락 액션 번호가 없으면 기존과 같이 구성 경고를 반환한다.
- 수락 성공 후 기존 후속 wakeup이 새 퀘스트 스냅샷을 조회한다.
- 새 스냅샷에서 퀘스트가 `진행 중`이면 몬스터 처치 또는 맵 클리어 자동전투를 실행한다.

## 범위

`QuestAutomationHandler`의 수락 후보 조건만 변경한다. 우선순위, 수락 후 cycle 생성, wakeup, 전투 실행 로직은 변경하지 않는다.

## 검증

- 미완료 아이템 반납 퀘스트도 선택되어 있으면 수락한다.
- 지원하지 않는 미션 유형도 선택되어 있으면 수락한다.
- 맵 클리어 퀘스트가 `수락 가능`이면 전투보다 먼저 수락한다.
- 기존 퀘스트 자동화 테스트 전체가 통과해야 한다.
